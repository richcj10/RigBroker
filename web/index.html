      Connect Winlink Express
       remote setup: Winlink runs on your PC, the radio stays on the Pi      
        
      
          
      The Pi tunes the radio and runs the modem; Winlink Express on your PC talks to it over the network.
            Only your PC can reach these ports (firewall). Nothing can transmit unless RigBroker has started a Winlink session.
      

          
      1. Start a session here first
      
          
        
            
      1. Packet: pick a gateway in Winlink gateways below (★ / Try) or press Start Winlink session: the radio tunes to that gateway and the packet modem starts.
        2. 
            
      2. VARA FM: press the vara_fm profile: the radio tunes and VARA FM starts on the Pi (about 10 s).
        3. 
            
      3. The radio is held for the session (lease timer on the radio card). Press Release when done; it returns to APRS.
        4. 
          
      

          
      2a. Winlink Express - Packet Winlink session
      
          
      
            
      Session type
      Packet Winlink
      
            
      TNC type
      KISS (Direwolf), connected over TCP/IP - not a serial port
      
            
      TCP host / address
      192.168.5.157
      
            
      TCP port
      8010
      
            
      Radio control in Winlink Express
      none / manual - RigBroker tunes the radio
      
          
      

          
      2b. Winlink Express - VARA FM Winlink session
      
          
      
            
      Session type
      VARA FM Winlink
      
            
      VARA TCP host / address
      192.168.5.157 (VARA runs on the Pi, not on the PC)
      
            
      VARA command port
      8300 (data port 8301)
      
            
      "Run VARA automatically"
      off - RigBroker starts VARA on the Pi
      
            
      Radio control / PTT in Winlink Express
      none - VARA on the Pi keys the radio through RigBroker's rig control
      
          
      

          
      3. Connect
      
          
        
            
      1. In the Winlink Express session window, choose the same gateway (callsign) you picked here, then Start.
        2. 
            
      2. Watch the radio card: TX lights while the Pi transmits; the S-meter shows the gateway.
        3.
